# Cinematic Commands

## Comando raíz

- `/cinematic`
- Alias: `/cine`

## Subcomandos

- `/cine play <nombre>`
  - Permiso: `cinematic.play`
  - Permiso extra para demo: `cinematic.demo.play`
  - Ejemplo: `/cine play demo`

- `/cine stop`
  - Permiso: `cinematic.stop`
  - Ejemplo: `/cine stop`

- `/cine pause`
  - Permiso: `cinematic.pause`
  - Ejemplo: `/cine pause`

- `/cine resume`
  - Permiso: `cinematic.resume`
  - Ejemplo: `/cine resume`

- `/cine list`
  - Permiso: `cinematic.list`
  - Ejemplo: `/cine list`

- `/cine reload`
  - Permiso: `cinematic.reload`
  - Ejemplo: `/cine reload`

- `/cine help [subcomando]`
  - Permiso: `cinematic.help`
  - Ejemplo general: `/cine help`
  - Ejemplo detallado: `/cine help play`
